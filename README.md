# 🚀 Exercícios de Lógica de Programação em Java

Este repositório contém uma série de exercícios práticos desenvolvidos em Java para o treinamento de lógica, manipulação de variáveis, operações matemáticas e interação com o usuário via console.

---

## 📁 Estrutura dos Exercícios

* **`exercicio01.java`**: Solicita um número inteiro ao usuário e o exibe na tela.
* **`exercicio02.java`**: Recebe dois números e realiza operações de soma, subtração e multiplicação.
* **`exercicio03.java`**: Calcula a média aritmética a partir de quatro notas bimestrais informadas.
* **`exercicio04.java`**: Simula o cálculo de pagamento em um posto, multiplicando o preço da gasolina pela quantidade de litros.
* **`exercicio05.java`**: Calcula o orçamento total de uma viagem para múltiplos destinos (Alemanha, Portugal e Itália), considerando o preço por pessoa e a quantidade de viajantes para cada país.

---

## 🛠️ Conceitos Aplicados

* **Entrada de Dados**: Utilização da classe `Scanner` para capturar dados do teclado.
* **Tipos de Variáveis**: Uso de `int` para números inteiros e quantidades, e `double` para valores monetários e médias.
* **Operadores Aritméticos**: Implementação de soma (`+`), subtração (`-`), multiplicação (`*`) e divisão (`/`).
* **Saída de Dados**: Formatação de mensagens para exibição de resultados ao usuário.

---

## 🚀 Como Executar

1.  **Pré-requisitos**: Ter o Java JDK instalado.
2.  **Compilação**: Abra o terminal na pasta do arquivo e digite:
    ```bash
    javac exercicio01.java
    ```
    *(Substitua o nome conforme o exercício desejado)*
3.  **Execução**:
    ```bash
    java exercicio01
    ```

---

## 📝 Notas de Implementação
* Todos os códigos incluem o fechamento do objeto `Scanner` (`scanner.close()`) para garantir o gerenciamento correto dos recursos do sistema.
* No `exercicio03.java`, a média é calculada dividindo a soma das quatro notas por 4.
